# suite-testes

Suíte automatizada de testes críticos dos projetos CódigoIAgil.

A suíte executa cada fase de teste com ferramentas reais, mostra a execução na tela,
guarda a saída bruta como evidência num registro encadeado por hash e só aprova
o que executou de fato.

Em construção — o plano está em `docs/PLANO.md` (etapa E1 em andamento).
